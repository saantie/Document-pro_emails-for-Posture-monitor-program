# จัดการสมาชิกโปร — 8Hrs Posture Monitor

หน้าเว็บ static ล้วนๆ (ไม่มี build step, ไม่มี backend) สำหรับดูรายชื่อลูกค้าที่สมัคร 8Hrs Pro,
เพิ่ม/ต่ออายุ/ลบสิทธิ์ และร่างอีเมลแจ้งเตือนลูกค้าที่ใกล้หมดอายุ เชื่อมกับ Firestore ของโปรเจกต์
`posture-monitor-program` ตรงๆ ผ่าน Firebase JS SDK

**หน้านี้เปิดถึงได้จากอินเทอร์เน็ตทุกคน (GitHub Pages เป็นของสาธารณะ) แต่แก้ข้อมูลไม่ได้ถ้าไม่ได้
ล็อกอินด้วยอีเมลผู้ดูแลที่กำหนดไว้ใน Firestore Rules** — ความปลอดภัยอยู่ที่ rules ไม่ใช่ที่การซ่อนลิงก์

## ต้องทำก่อนใช้งานได้จริง (ทำครั้งเดียว)

### 1. deploy Firestore Rules ที่รองรับผู้ดูแล

ไปที่ **Firebase Console → posture-monitor-program → Firestore Database → Rules** แล้ววาง
เนื้อหาจากไฟล์ `firestore.rules.proposed` ในโปรเจกต์หลัก (`F:\posture_monitor\posture_monitor\`)

**สำคัญ:** ไฟล์นั้นมีบรรทัด

```javascript
function isAdmin() {
  return request.auth != null && request.auth.token.email == 'saantie@gmail.com';
}
```

ถ้าเปลี่ยนอีเมลที่ใช้ดูแล ต้องแก้บรรทัดนี้ให้ตรงกับอีเมลที่จะใช้ล็อกอินหน้านี้เป๊ะ ไม่งั้นจะเข้าไม่ได้

⚠️ **rule เดิมที่ deploy อยู่ตอนนี้ (`allow read: if request.auth != null;`) มีรูรั่วจริง** — ลูกค้า
คนไหนก็ตามที่ล็อกอินเข้าแอปสามารถอ่านข้อมูล `pro_emails` ของลูกค้าคนอื่นได้ทั้งหมด (อีเมล/แพ็กเกจ/
สถานะ/วันหมดอายุ) ไม่ใช่แค่ของตัวเอง ต้อง deploy rule ใหม่นี้ทับโดยเร็วเพื่อปิดรูรั่ว ไม่ใช่แค่เพื่อ
ให้ admin dashboard ใช้งานได้

### 2. ตรวจว่ามีบัญชีผู้ดูแลใน Firebase Authentication แล้ว

**Firebase Console → Authentication → Users** ต้องเห็นอีเมลที่ตรงกับ `isAdmin()` ข้างบน ถ้ายังไม่มี
ให้กด **Add user** สร้างเอง หรือสมัครผ่านหน้า login ของแอป 8Hrs เองก็ได้

### 2.5 (ถ้าจะล็อกอินด้วย Google) เปิด Google เป็นช่องทางล็อกอิน + อนุญาตโดเมนนี้

หน้านี้มีปุ่ม "เข้าสู่ระบบด้วย Google" ด้วย ใช้ได้ก็ต่อเมื่อตั้งค่า 2 อย่างนี้ก่อน:

1. **Firebase Console → Authentication → Sign-in method** → เปิด **Google** (ถ้ายังไม่เปิด) → ใส่
   support email แล้ว Save
2. **Firebase Console → Authentication → Settings → Authorized domains** → กด **Add domain** →
   ใส่โดเมนของ GitHub Pages (เช่น `saantie.github.io`) — **ถ้าไม่เพิ่มโดเมนนี้ ปุ่ม Google จะขึ้น
   error `unauthorized-domain` ทันที**

ล็อกอินด้วย Google ใช้บัญชี Google ที่มีอีเมลตรงกับ `isAdmin()` ข้างบน (เช่น `saantie@gmail.com`)
— ผลลัพธ์เหมือนล็อกอินด้วยรหัสผ่านทุกประการ เพราะ Firestore rule เช็คแค่อีเมล ไม่สนวิธีล็อกอิน

### 3. เปิด GitHub Pages

**Settings → Pages** ของ repo นี้ → Source เลือก **Deploy from a branch** → Branch เลือก `main` /
`(root)` → Save รอ 1-2 นาที จะได้ลิงก์หน้าตาประมาณ

```
https://saantie.github.io/Document-pro_emails-for-Posture-monitor-program/
```

บันทึกลิงก์นี้ไว้ (bookmark) ใช้เข้าดู/จัดการลูกค้าได้จากที่ไหนก็ได้

## วิธีใช้

- **เข้าสู่ระบบ** ด้วยอีเมล/รหัสผ่านบัญชีผู้ดูแล (บัญชีเดียวกับที่ตั้งไว้ใน `isAdmin()`)
- ตารางแสดงลูกค้าทั้งหมด เรียงตามวันหมดอายุ ใกล้สุดขึ้นก่อน:
  - 🔴 พื้นแดง = หมดอายุแล้ว
  - 🟡 พื้นเหลือง = เหลือไม่เกิน 7 วัน
  - ขาว = ปกติ
  - เทาเอียง = ข้อมูลไม่ครบ (ไม่มีวันหมดอายุ — ต้องแก้ไข)
- **+ เพิ่มลูกค้าใหม่** — กรอกอีเมล/แพ็กเกจ/ช่องทาง/วันหมดอายุ (มีปุ่ม +30/+365/+7 วันให้กดเร็ว)
- **แก้ไข** ในแต่ละแถว — ใช้ต่ออายุลูกค้าเดิมได้เลย (แก้แค่วันหมดอายุ)
- **แจ้งเตือน** — เปิดร่างอีเมลในโปรแกรมอีเมลเริ่มต้นของเครื่อง (mailto:) กรอกให้ครบแล้ว
  **ตรวจดูก่อนแล้วกดส่งเอง** ไม่มีการส่งอัตโนมัติ
- **ลบ** — เพิกถอนสิทธิ์ทันที (ลบ document ทิ้ง กู้คืนไม่ได้ ต้องเพิ่มใหม่เอง)

## ข้อจำกัดที่ตั้งใจ

- ไม่มีการส่งอีเมลอัตโนมัติ — กันความผิดพลาด (พิมพ์ผิด/ส่งซ้ำ) และไม่ต้องผูกบริการอีเมลเพิ่ม
  ถ้าอยากได้แบบส่งอัตโนมัติทีหลัง ต้องเพิ่มบริการส่งอีเมล (เช่น SendGrid/Resend) และ Cloud
  Function ซึ่งต้องใช้ Firebase แพ็กเกจ Blaze
- วันหมดอายุนับเป็น 23:59:59 ตามเวลาเครื่องที่ใช้กรอก (ไม่ใช่เวลาเซิร์ฟเวอร์) — คลาดเคลื่อนได้
  ไม่กี่ชั่วโมงถ้าเปิดจากเครื่องคนละ timezone แต่ในทางปฏิบัติผู้ดูแลใช้เครื่องเดียวเป็นหลัก
